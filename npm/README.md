# @qfeius/makecli

makecli — agentic development platform cli. This package installs a prebuilt binary for your platform via `optionalDependencies`; no download happens at install time.

```bash
npm install -g @qfeius/makecli
makecli version
```

Beta channel:

```bash
npm install -g @qfeius/makecli@beta
```

Supported platforms: macOS / Linux / Windows on x64 and arm64. Source, issues and release notes: https://github.com/qfeius/makecli
